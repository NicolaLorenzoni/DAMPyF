# DAMPyF

DAMPyF implements dissipation-assisted matrix product factorisation (DAMPF) for open quantum systems coupled to
structured bosonic environments represented by pseudomodes. It uses matrix product states and Ray parallelization
to simulate energy-transfer dynamics and linear optical spectra through an importable Python API with model
parameters supplied as NumPy arrays.

The `test_examples` scripts run simulations and plot comparisons with stored reference data.
